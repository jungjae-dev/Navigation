# 요구사항 — 시간여행 슬라이더

출처: Documents/Work/260614_service_review/07_killer_features.md (PART 2)
제품 방향: 도보 메인 + 살아있는 데이터 지도. 서울 공공데이터만 사용.
대상 단계: speckit-specify 입력 브리프

---

## 1. 개요 / 목적
지도에 **요일 × 시간** 슬라이더를 두고, 그 시간대의 인구·혼잡·대기질을 지도 히트맵으로 **재생**한다. 도시가 하루 동안 변하는 모습을 손가락으로 돌려본다.
- 기본 = **요일별 평소 패턴**(생활인구 통계, 미리 계산해 저장).
- 강화 = **오늘 vs 평소**(실시간 도시데이터로 평소 대비 비교).
- 시각 임팩트 최상 → 마케팅·바이럴 훅. 핀 인사이트의 시간 곡선과 데이터 공유.

## 2. 목표 / 비목표
- 목표: 요일별 시간대 패턴을 지도 애니메이션으로. "이 동네 금요일 밤엔?" 류 질문 해결.
- 비목표(MVP): 골목 단위 정밀도(행정동 단위), 전 지역 실시간(주요지점만 실시간), 미래 예측 API 의존.

## 3. 사용자 시나리오
- (이사) "이 동네 밤엔 조용한가? 새벽 인적은?"
- (나들이) "그 한강공원 토요일 몇 시에 한산?"
- (자영업자) "내 가게 앞 손님 몰리는 시간대"
- (안전) "이 골목 몇 시부터 인적 끊기나" (06 밤길 안심과 연결)

## 4. 기능 요구사항 (FR)
- **FR-0 진입**: 홈 `MapControlButtonsView`에 **전용 플로팅 버튼**(시계/타임라인 아이콘) → 탭 시 시간여행 모드 진입(히트맵 ON + 슬라이더 드로어).
- **FR-1 슬라이더 UI**: 2축 컨트롤 — 요일(월~일) 선택 + 시간(00~24) 스크럽 + 재생(▶) 버튼. 슬라이더는 하단 드로어에 배치.
- **FR-2 모드 토글**: 인구밀도 / 혼잡도 / 대기질 / 연령필터(예: 20대만).
- **FR-3 요일별 패턴 데이터**: 생활인구(일자×시간×행정동×성별·연령)에서 **최근 4~8주 요일 평균** 산출(공휴일 제외). 결과를 요일×시간×행정동 테이블로 저장.
- **FR-4 히트맵 렌더링**: **(A) 면 색칠(단계구분도) MVP 채택**. 경계는 **`vuski/admdongkor`의 2016 시점 스냅샷(ver2016xx)** 사용 → 생활인구(2016 코드 고정)와 정합(불일치 거의 0). 코드는 문자열 처리(앞자리 0 보존), 8↔10자리 변환 주의. 폴백(B) 히트블롭은 비상용. 시간 변경 시 **프레임 보간(crossfade)**, 반투명.
- **FR-5 타임랩스 재생**: ▶ 누르면 00→24 자동 진행 애니메이션(속도 조절 옵션).
- **FR-6 연령 필터**: 생활인구 연령대 컬럼으로 "특정 연령이 몰리는 시간/장소".
- **FR-7 오늘 vs 평소**: 실시간 도시데이터(citydata) 주요 지점 → "지금 강남, 평소 금요일보다 20% 한산" 배지.
- **FR-8 지점 시간곡선**: 특정 행정동/핀 선택 시 24시간 추이 그래프(핀 인사이트 연동).
- **FR-9 기준선 옵션**: 기본=요일 평균, 옵션=지난주 그 요일(전주).

## 5. 데이터 소스 (API 검증 완료 2026-06-19)
| 레이어 | 데이터셋(검증) | 성격 | 범위 |
|---|---|---|---|
| 요일별 패턴(기본) | 행정동 생활인구 OA-14991 — 일자×시간(0~23)×행정동×성별×연령 **모두 포함 확인** | 통계, **CSV 다운로드 후 미리 계산** | 전 지역(~424동) |
| 오늘 vs 평소(강화) | 실시간 도시데이터 citydata — 혼잡도+**미래 12h 예측** 필드 확인 | 라이브 | 주요 ~120곳 |
| 대기질 모드 | RealtimeCityAir OA-1200 | 시간 | 자치구 |
| 행정동 경계 | `vuski/admdongkor` GeoJSON(자유이용·최신) 또는 통계청 SGIS | 정적 | 면 색칠용 |

**검증 메모**: 생활인구 공공누리 1유형(상업 OK·출처표시). 과거 누적은 OpenAPI가 최근 2개월만 → **월별 CSV(ZIP) 다운로드 필수**. **3명 이하 마스킹(`*`)** 셀 보간 필요. citydata 과거 시계열은 API 노출 미확인 → "평소"는 생활인구 요일평균으로 충당.

## 6. 전처리 파이프라인 (핵심)
1. 생활인구 원본 다운로드(서울 열린데이터광장).
2. 일자→요일 매핑, 공휴일 제외, **요일×시간×행정동(×연령) 평균** 계산.
3. 압축 테이블 생성(예: 행정동 425 × 24시간 × 7요일 × 모드).
4. 앱 번들 또는 원격(Gist/CDN)에 저장 → 앱은 로컬 조회.
5. 갱신 주기(월 1회 등) 정의.
6. **마스킹(`*`, 3명 이하) 셀 보간**, 결측 시간대 처리.
7. 경계는 **2016 시점 GeoJSON**(vuski ver2016xx) 사용 → 코드 정합. 최신 경계 쓸 경우만 한 자릿수 예외 동(강일/상일1·2동, 개포3동 등) 매핑 테이블. 분동 케이스는 모동 값 분배 또는 폴리곤 dissolve.

## 7. 기술 구현 노트
- 패턴: MVVM + Combine, `CurrentValueSubject`로 (요일,시간,모드) 상태 관리.
- 렌더링: MapKit `MKMultiPolygon` 오버레이 + 값→색 매핑, 또는 커스텀 히트맵 타일. 프레임 보간으로 재생.
- 데이터: 미리 계산본 로컬 로드 → **실시간 API 호출 거의 없음**(빠르고 오프라인 가능). citydata는 "오늘 vs 평소"에만.
- 성능: 폴리곤 수가 많아 렌더 비용 → 줌 레벨별 LOD, 보이는 영역만 갱신.

## 8. 비기능 요구사항
- 부드러운 재생(목표 프레임률 유지).
- 데이터 크기 최소화(압축, 정수 양자화).
- 오프라인: 미리 계산본으로 패턴 재생 가능.
- 색각 접근성: 단계 색상 WCAG/색각 고려, Theme.Palette 경유.

## 9. 엣지 케이스
- 결측 시간대/행정동 → 보간 또는 회색.
- 공휴일/특이일 → 평균에서 제외.
- 신규·통폐합 행정동 → 경계/코드 불일치 처리.
- 실시간 비교 불가 지역(citydata 미포함) → 비교 배지 숨김.

## 10. 확인 필요 (검증 반영)
- ✅ **해결**: 생활인구 컬럼(일자×시간×행정동×성별×연령) 확인 / 요일평균 전처리 현실적(하루 ~1만행) / 행정동 경계 `vuski/admdongkor` 자유이용 확보 / citydata 미래 12h 예측 필드 확인.
- ✅ **추가 해결**: 조인 리스크 = 소수(426개 중 한 자릿수) → **2016 시점 경계 사용으로 정합**, choropleth 현실적.
- 남은 검증(실데이터 1회): ① 생활인구 CSV 헤더가 8자리/10자리 코드인지 + 연령대 컬럼 라벨 verbatim ② citydata 과거 시계열 API 노출 여부(없으면 평소=요일평균).

## 11. MVP 범위
- MVP: 인구밀도 모드 + 요일별 패턴 재생(FR-0,1,3,4,5) + 지점 시간곡선(FR-8). 렌더링 **면 색칠(A)**, 조인 검증 실패 시 히트블롭(B) 폴백.
- Later: 혼잡/대기질 모드, 연령 필터, 오늘 vs 평소, 속도 조절.

## 12. 현 앱 통합 (Integration)
현 구조: 탭바 없음 → `HomeViewController(루트)` + 내장 `MapViewController` + `DrawerContainerManager`. 시간여행은 **데이터 레이어(히트맵) + 시간 컨트롤 드로어** 한 쌍의 "모드".

### 진입 (전용 버튼)
- `Feature/Home/MapControlButtonsView`에 **전용 플로팅 버튼**(시계/타임라인 아이콘) 추가 → 콜백 → `AppCoordinator.showTimeTravel()`.
- (따릉이/버스처럼 POI 레이어 메뉴에 묻지 않고, 시그니처 기능이라 버튼으로 노출)

### 활성화 시 동작 (pushDrawer 방식)
드로어는 **한 번에 하나만** 보이는 스왑 구조([DrawerContainerManager `pushDrawer`](../../../Navigation/Navigation/Common/UI/DrawerContainerManager.swift)). 진입 시:
1. 지도: `MapViewController.setTimeline(...)` 로 **히트맵 오버레이 ON**.
2. 드로어: `drawerManager.pushDrawer(TimelineDrawerVC, 낮은 높이)` → **홈 드로어(검색바)가 내려가고 슬라이더 드로어가 올라옴**(POI 팝업과 동일 경험). `replaceStack` 아님(종료 시 홈 복원 위해 push).

### 진입 시 기존 홈 요소 처리 (확정)
| 요소 | 처리 | 비고 |
|---|---|---|
| 홈 드로어(검색바) | 아래로 내려가 숨김 | pushDrawer 기본 동작 |
| 따릉이·버스 레이어 | **자동 OFF (배타)** | 히트맵과 겹침 방지 |
| 지도모드(위성) | 표준 지도로 고정 | 위성 위 히트맵 가독성 |
| 현재위치 버튼 | 유지 | 내 동네 찾기 |
| 지도 카메라 | **현재 영역 유지** | 급이동 방지 |

### 종료
- TimelineDrawer 닫기 → `popDrawer` → **히트맵 오버레이 clear** → **진입 전 레이어 상태 복원** → 홈 드로어(검색바) 복귀. 오버레이 생명주기는 드로어에 묶음.

### 탭 인터랙션
- 히트맵의 동네 탭 → 그 행정동 24h 곡선(FR-8). 1번 핀 인사이트 팝업의 시간곡선 카드와 연동 가능(Later).

### 신규 파일 / 재사용
- 신규: `Feature/Timeline/`(TimelineDrawerViewController, TimelineViewModel[`CurrentValueSubject<(요일,시간,모드)>`], TimeTile 모델), `Map/Overlay/TimelineChoroplethOverlay`(+Renderer, `MKMultiPolygon` 면 색칠 / 폴백 히트블롭). `MapViewController.setTimeline/clearTimeline`. `MapControlButtonsView` 버튼 + `AppCoordinator.showTimeTravel/exitTimeTravel`.
- 재사용: `DrawerContainerManager`(push/pop), 레이어 토글 패턴(따릉이 `BikeViewModel` → 구독 → `MapViewController.setX`), `Theme` 토큰.
- 데이터: 요일별 미리계산 테이블 로컬 로드(실시간 호출 거의 없음).
