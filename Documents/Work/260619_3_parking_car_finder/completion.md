# 완료 기록 — 지하주차장 내 차 찾기 (브랜치 008-parking-car-finder, specs/005)

기간: 2026-07-10(스펙) ~ 2026-09-11(설계 개정 v2) | 커밋 18개 | 테스트 142건 green

## 배포 범위 (MVP)
- **스캔 등록**(US1): 진입 즉시 카메라 스캔 → 코드 자동 인식·최근접 목표 자동 저장·인식 프레임 사진·인접 코드 부산물. 층 토큰 없으면 층 시트
- **되찾기**(US2): OCR+AR 랜드마크 맵 → 단계적 격자 추정(1D/2D) → 2D HUD 화살표+신뢰도, 그라디언트 힌트(구역 크기·번호 warmer/colder), 도착=목표 직접 인식(연속 2회)
- **수동 폴백**(US3): 권한 거부·인식 불가 시 코드 입력+층+사진
- **허브 구조**: 요약 카드 중심, 폴백 겸용. 수명주기(활성 1·대체·완료 보관 1)
- **디버그**(DR): 출시 빌드 포함·기본 off — AR 오버레이·상태 스트립·NDJSON 레코딩·리플레이·DevTools 목록(공유/삭제)

## 검증
- 유닛 142건: 파서·CRUD·GridEstimator(가드 포함)·힌트·리플레이(현장 픽스처 8건)
- 현장 3회(주차장 3곳, 코드 체계 N/ZN): 도착 확정 3회 성공, 오검출 격자 오염 0건
- 전체 회귀: MapMatcher/TurnType 각 1건 실패는 main 기존 결함(260710 확인) — 본 기능 무관

## 현장 루프가 만든 수정 (로그→리플레이→픽스처 사이클 4회)
1. 선행 0 정규화("09"/"9") + 도착 파싱 동치 (260710)
2. 신선도 필터·신뢰도 상한·sceneDepth 폴백 — 위치 확보율 12%→36~55% (260801)
3. 다중 표지판(동일 코드 7~13m 복수 위치) 모호 제외 + 힌트 위치무관 확장 (260911)
4. **설계 개정 v2** (Opus/Sonnet 교차 검증): 잔차 강등의 구조적 사망(3점 정확결정계) 발견 →
   3중 가드(외삽 레버≤2.5·축 간격 1~15m/스텝·표시 60m 상한)로 교체, 주 지표를
   화살표 가동률·targetEst 자기불안정성으로 교체 — Documents/Work/260911_design_review/design_revision.md
