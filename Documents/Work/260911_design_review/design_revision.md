## 1. 검증에서 판명된 사실

### 1-1. 기존 분석에서 철회·정정된 것

| 기존 주장 | 판정 | 근거 |
|---|---|---|
| 점프 분포 "2~7m 완전 공백" → 임계 4m는 데이터 검증됨 | **철회** | 260801 F3에 4.87m 점프(1.0초 간격) 실존. 실공백은 [0.8, 4.87) — 0.9~4.8 어느 임계든 결과 동일. 4.87m 점프는 표지판·드리프트가 아니라 **raycast `.any` 폴백의 바닥 오탐** 서명 |

### 1-2. 신규 발견 결함 (교차 검증의 수확)

1. 🔴 **강등(FR-012) 구조적 사망**: 아핀 미지수 6 = 관측 3개 방정식 6 → 정확결정계라 **잔차 항등 0**.
   격자 안내의 최빈 구성(관측 3)에서 모순 감지 발동 불가, 신뢰도의 `잔차<1.0`도 자동 충족.
   실측: gridGuidance 중 잔차==0 비율 47/81/100/8%, 전 세션 degraded 0건
2. 🔴 **무제한 외삽**: J21 세션 — B~D구역에서 J구역까지 6스텝 외삽, 60초간 54~116m 화살표를
   medium으로 표시, 미도착 이탈. 외삽 레버 √(aᵀM⁻¹a)는 기존 행렬에서 공짜 계산되며
   실패(3.61·6.98) vs 성공(1.50) 세션을 정확히 분류하는데 미사용
3. 🔴 **화살표 가동률 실측 붕괴**: 현행 규칙 소급 시 6세션 중 3세션 화살표 0% (쌍둥이 없는
   260801 포함 — 신선도 필터 단독으로 전멸). 뜨는 세션도 갱신의 80~100%가 10m 초과 오차
4. 🟠 **계측 버그**: `ParkingEventRecorder.trackingChanged` 호출부 없음 — 전 세션 0건은
   "정상"이 아니라 미수집. 드리프트·좌표계 점프 논증의 데이터 공백
5. 🟠 **zoneIndex = ASCII 오프셋**: 주차장이 관례적으로 건너뛰는 글자(F·I·O — 260911에서 F·I
   미관측) 미처리 → 구역 서수가 어긋나면 기하·기호 채널 동시 오염
6. 🟠 **중단 복구 전손**: 인터럽션 시 관측 전파기 → 재안내까지 실측 21~33초 (전화 1통의 비용)

### 1-3. 검증을 통과·강화된 것

- **다중 표지판 발견(A4)**: 기전 소수점 재현 (J23 재앵커 → numVec 21.5m/스텝 → 30.3m) — 가장 견고
- **기호 척추 우선(C1)**: 힌트 가용 6/6 세션·1.7~9.0초 vs 화살표 3/6 세션·24초+ — 정량적으로 압도
- **국소 맵(C2)**: 유지 — 단 근거를 드리프트 → 피치 비균일+연관 오류로 교체(더 강한 근거)
- **깊이 폴백(A2)**: 확보율 수치 정확 — 단 "개선 서사"는 비지지 (원거리=저품질 관측 추가 측면)

## 2. 설계 변경 결정

### 유지
- 랜드마크(기둥 코드) 접근, 도착=직접 인식(연속 2회), 완전 로컬·무인프라
- 기호 척추(그라디언트 힌트 기본) + 기하 보강(화살표) — **강화 확정**
- 세션 국소 맵(전역 지도 없음), 다중 표지판 제외(임계 4m — 단 "경험적 상수"로 지위 정정)
- 로그→리플레이→픽스처 튜닝 루프

### 교체 ①: 문제 진단 — "지각 병목" → "추정 가드 병목"
개선 투자 우선순위를 지각(확보율·드리프트 대응)에서 **추정 가드(연관·모델·외삽)**로 역전.

### 교체 ②: 안전판 — 잔차 기반 강등 → 3중 가드 (FR-012 재정의 필요)
잔차는 관측≤3에서 항등 0이라 안전판 역할 불가. 대체:
- **G1 외삽 레버 상한**: √(aᵀM⁻¹a) > 임계(초기값 ~2.5, 실측 성공 1.5/실패 3.6·7.0 사이)
  → 기하 화살표 끄고 기호 힌트로
- **G2 축 벡터 크기 사전확률**: 스텝당 2~15m 범위 밖 축 → 피팅 기각 (21.5m/스텝 차단)
- **G3 표시 거리 상한**: 주차장 물리 규모(~60m) 초과 목표 표시 금지 (102m 표시 차단)
- 잔차는 관측 ≥4일 때만 신뢰도·강등 신호로 유효
실측 검증: G1~G3이 실패 세션(J21·J22) 전부 차단, 성공 세션(H22·260801 초기) 통과.

### 교체 ③: "만료" 패러다임 → "불확실성 팽창" 패러다임
30초(또는 거리) 이진 컷오프는 260801에서도 화살표를 전멸시킴(과잉 억제).
→ 관측·추정에 불확실성을 부여해 시간 아닌 **이동거리에 비례해 점진 팽창**,
화살표 소멸은 불확실성 한계 초과의 결과로만. 코스팅·거리 신선도 논의는 이것으로 흡수.
(구현은 가드 ② 안정화 이후 — 순서 중요: 강건 연관 없이 추정을 오래 살리면 오염 연장)

### 격하·보류
| 항목 | 결정 |
|---|---|
| 코스팅 50m 고정 상한 | 폐기 — ③의 불확실성 동반 형태로만, ② 이후 |
| ±Nm 오차 표시 | 보류 — ② 이후 조건부 (공분산만으론 연관 오류를 못 잡아 "세련되게 틀림") |
| 기호 힌트 방향 어휘("더 뒤쪽") | 금지 — 구역 순서(F·I 건너뜀) 검증 전까지 크기·근접 표현만 |
| 주 튜닝 지표 "도착 오차" | 교체 — **targetEst 자기불안정성**(한-스텝 점프·누적 이동)을 주 지표로. 전 세션 계산 가능, 실패 세션(44.2m/41.9m 점프) 정확 분류 |
