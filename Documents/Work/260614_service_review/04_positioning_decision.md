# 3단계 포지셔닝 결정 — 가설 비교

작성일: 2026-06-19
입력: 01(인벤토리·비전), 02(시장조사), 03(공공데이터)

---

## 조사로 확정된 사실 (결정의 전제)
- ❌ **AR은 간판에서 제외.** 네이버 실내 AR(2025-10 COEX), LG U+ 차량 AR(2020) 선점 + 지하주차장은 공공 데이터 토대 없음.
- ✅ **이동수단 특화는 유효.** komoot 4천만 명이 입증.
- ✅ **서울 실시간 데이터 레이어는 토대 충분**(소통·혼잡도·대기질·따릉이·실내지도 API, KOGL 상업이용 OK).
- ✅ **가벼움·깔끔함 UX 공백은 실재**(정성적). 거대 앱은 무겁고 광고로 산만.
- ⚠️ **무료+광고 단독 수익은 위험.** 제휴/구독 혼합 필요.

---

## 세 가지 포지셔닝 안

### 안 A′ — 이동수단 특화 내비 (AR 제거판)
> "도보·자전거·대중교통에 특화된, 가볍고 깔끔한 길안내 앱."
- 강점: komoot로 검증된 모델, 기존 코드(따릉이·버스·지하철·도보) 직접 재활용, 명확한 타깃.
- 약점: 네이버·카카오도 도보/대중교통은 함. **"특화의 깊이"로 이겨야** 함(예: 자전거 전용 라우팅·안전경로). 자전거 전용도로 데이터는 보강 필요(OSM 등).
- 수익: 모빌리티 제휴(따릉이/공유 PM), 자전거 고급기능 구독.

### 안 B — 살아있는 데이터 지도
> "서울을 가장 예쁘게 보여주는, 실시간 데이터 지도."
- 강점: 데이터 리스크 최저, 시각적 임팩트 큼(소통선·혼잡도 히트맵·대기질·AI예측), "가벼움+깔끔" UX와 직결, 차별화가 디자인·큐레이션이라 대기업이 흉내내도 무겁다.
- 약점: "내비"라기보다 "지도/정보 앱"에 가까워져 기존 길안내 자산 활용도가 낮아짐. 수익화 경로가 더 모호.
- 수익: 지역상권 제휴, 광고(데이터 레이어 스폰서), 데이터 큐레이션.

### 안 C — 결합 (권고 후보)
> "가볍고 깔끔한 **도보·자전거·대중교통 특화 내비** + 서울 실시간 데이터를 예쁘게 얹은 지도."
- A′의 길안내 골격(이미 구현된 자산) + B의 시각 데이터 레이어(차별화·재방문 유인)를 합침.
- AR은 **장기 옵션(옥외 도보 AR만, 실내·주차 제외)** 으로 보류.
- 강점: 기존 코드 최대 활용 + 낮은 데이터 리스크 + 명확한 UX 차별화(가벼움) + 데이터 레이어로 "매일 열 이유" 제공.
- 약점: 범위가 넓어 MVP 스코프 규율이 필요. "특화 깊이 vs 데이터 폭" 사이 우선순위를 MVP에서 분명히 해야.
- 수익: 모빌리티·지역 제휴 + 고급기능 구독 + (규모 도달 시)광고.

---

## 권고
**안 C(결합)**, 단 MVP는 **하나의 이동수단을 "주인공"으로** 좁혀 시작.
- 1순위 주인공 후보: **자전거/마이크로모빌리티** (따릉이 실시간 자산 강함 + komoot형 특화 검증 + 거대앱이 가장 약한 영역) 또는 **도보**(공중화장실·안심경로·문화행사 등 도보 데이터 풍부).
- 데이터 레이어는 MVP에 1~2개만(실시간 소통 or 혼잡도 + 따릉이) 얹어 "가벼운데 살아있다"를 증명.
