# 서울 공공데이터 × 지도 — 획기적 기능 아이디어 (브레인스토밍)

작성일: 2026-06-19
목적: 개발 아직 안 함. "기존 지도앱(네이버·카카오·티맵)에 없는, 공공데이터를 지도로 표출한 획기적 항목" 발굴
필터: 신규성(기존앱 안 함) × 시각 임팩트 × 도보 메인 적합 × 데이터 실재
판단 기준: 기존 앱이 "정보 패널"로는 보여줘도, **경로/레이어/추천**으로 안 쓰는 것 = 공백

---

## ⭐ TOP 5 — 가장 획기적 (도보 정체성과 찰떡)

### 1. 그늘길 / 햇빛길 (계절·시간 적응형)
- **컨셉**: 여름엔 "그늘로 걷는 길", 겨울엔 "햇빛 드는 길" 추천·하이라이트.
- **데이터**: 건물 높이(국토부 건물통합정보) + 가로수(서울 가로수 데이터) + 태양 고도(계산) + 폭염특보.
- **지도 표현**: 경로를 그늘 비율로 색칠 + 그늘 우선 경로 옵션.
- **왜 획기적**: 한국 어떤 지도앱도 안 함(구글이 해외 실험만). 도보 사용자 체감 효용 극대. **여름 한국에 강력.**
- **난도**: 상 (그림자 계산 필요). 단순화: 가로수 밀도 + 건물 그림자 근사.

### 2. 밤길 안심 히트맵 / 안심 경로
- **컨셉**: "가장 밝고 사람·감시가 많은 밤길" 추천. 어두운 골목 회피.
- **데이터**: 보안등·가로등 + 방범 CCTV + 안심귀갓길(362개 경로) + 여성안심지킴이집.
- **지도 표현**: 야간 밝기/안전 밀도 히트맵 + 안심 경로 라인.
- **왜 획기적**: 기존앱은 안심귀갓길을 "경로 추천"으로 안 씀. 야간 보행자(여성·1인가구) 명확한 수요.
- **난도**: 중 (데이터 자치구 분산 병합 필요, CCTV 라이선스 주의).

### 3. 계단 없는 길 / 무장애 접근성 경로
- **컨셉**: "계단 0, 엘리베이터 경유" 경로. 유아차·휠체어·캐리어·고령자.
- **데이터**: 서울 보도 네트워크(노드-링크, 계단/경사 속성) + 지하철역 엘리베이터/경사로 위치.
- **지도 표현**: 계단 구간 표시 + 무장애 경로 토글.
- **왜 획기적**: 거대앱이 "도보 경로"는 줘도 **무장애 경로는 거의 방치.** 사회적 가치 + 명확한 타깃 + 보조금/제휴 여지.
- **난도**: 중 (보도 네트워크 데이터 품질 검증 필요).

### 4. 한적한 길 / 혼잡 회피 산책 (시간 예측형)
- **컨셉**: "지금/도착시점에 사람 적은 길·공원" 추천. 조깅·산책·데이트.
- **데이터**: 생활인구(집계구/행정동, 시간대별) + 실시간 도시데이터(혼잡도 + AI 12시간 예측).
- **지도 표현**: 시간대별 인구밀도 히트맵(애니메이션) + 한적 경로.
- **왜 획기적**: **도착 시각 혼잡도 예측**은 어떤 앱도 안 함. "30분 뒤 그 공원 붐빌까?"가 가능.
- **난도**: 중.

### 5. 맑은 길 (대기질 적응 경로)
- **컨셉**: 미세먼지·오존 적은 경로 추천. 조깅·등하교·산책.
- **데이터**: 측정소별 실시간 대기질(에어코리아) + 자치구별 실시간 + 보간.
- **지도 표현**: 대기질 단계구분도/히트맵 + "맑은 길" 경로.
- **왜 획기적**: 기존앱은 대기질을 "숫자 위젯"으로만. **경로 차원으로 쓰는 건 신규.**
- **난도**: 중 (측정소 희소 → 보간 품질).

## 🔵 TIER A — 참신하고 시각 임팩트 큼

### 6. 조용한 길 (소음 회피 산책)
- 소음 측정망 데이터 → 조용한 산책로. 그늘길·맑은길과 묶어 "웰니스 워킹" 패키지.

### 7. 동네 체감 환경 레이어 (S-DoT IoT 센서)
- 시내 1,100대 센서의 실시간 기온·소음·진동·풍속 → 마이크로 기후 히트맵. "우리 동네 지금 체감". **소비자에게 S-DoT 노출하는 앱 전무.**

### 8. 비 오면 잠기는 길 경고 (침수 레이어)
- 침수흔적도/예상도 + 호우특보 → "이 길 잠긴다" 실시간 경고. 도보·자전거 안전.

### 9. 계절 산책 지도 (벚꽃·단풍·은행)
- 가로수(수종) + 공원 + 개화/단풍 시기 → "지금 예쁜 산책로". 강한 계절성·SNS 공유성.

### 10. "지금 열리는 것" 레이어
- 문화행사·축제·공연 위치 + 시간축 → "내 주변 30분 안에 시작하는 행사". 도보 탐험·발견.

---

## 🟡 TIER B — 보조 / 일부 기존 존재

### 11. 거리 활기 지도
- 유동인구 + 상권 추정매출 → "지금 활기있는 거리 vs 한적한 골목". 관광·데이트.

### 12. 응급 안전 레이어
- AED + 응급실 실시간 가용병상. (일부 앱 AED 있음 → 신규성 낮음, but 실시간 병상은 드묾)

## 묶음 전략 (개별보다 패키지)
- **"웰니스 워킹"** = 그늘길(1) + 맑은길(5) + 조용한길(6) + 한적한길(4) → 도보 정체성의 간판.
- **"안심 워킹"** = 밤길 안심(2) + 침수 경고(8) + 무장애(3) → 안전 축.
- **"발견 워킹"** = 계절 산책(9) + 지금 열리는 것(10) + 활기 지도(11) → 탐험 축.

→ 이 세 축이 "거대앱이 안 하는, 도보 특화 데이터 큐레이션"이라는 차별화(04·05의 핵심 승부처)를 구체화함.
