# Contracts: 소비하는 외부 API (서울 공공데이터 + Kakao)

이 기능은 외부 인터페이스를 **노출하지 않고**, 아래 API를 **소비**한다. 각 카드는 해당 계약에 의존한다. 인증키는 `Secrets.xcconfig`.

## C0. Kakao coord2regioncode (좌표→행정동)
- 요청: `x`(경도), `y`(위도), 기본 WGS84
- 응답 핵심: `region_1depth_name`(시), `region_2depth_name`(자치구), `region_3depth_name`(행정동), `code`(지역코드)
- 실패: 네트워크/한도 초과 → 역지오코딩 폴백 또는 "동네 식별 불가"

## C1. 생활 활기 — 행정동 생활인구 (OA-14991)
- 요청: 행정동코드 + (선택)시간대
- 응답 핵심: 시간대별 총생활인구수 → 활기 등급 산출. **좌표 없음**(coord2regioncode 매칭)
- 라이선스: 공공누리 1유형

## C2. 대기질 — RealtimeCityAir (OA-1200)
- 요청: 자치구명/전체
- 응답 핵심: `MSRSTE_NM`(자치구), `IDEX_MVL`/`IDEX_NM`(통합대기환경지수/등급), PM10/PM2.5
- 실시간(시간 갱신) → `asOf` 표시

## C3. 교통 — 따릉이 실시간 (OA-15493)
- 응답 핵심: `stationLatitude`/`stationLongitude`, `parkingBikeTotCnt`(잔여)
- 반경 500m 필터, 실시간 → `asOf` 표시

## C4. 교통 — 지하철역 좌표 (OA-22534) / 버스정류소 (OA-15067·OA-1094)
- 지하철: CSV(위경도, 변환 불필요) → 최근접 역 + 도보분 추정
- 버스: 좌표(EPSG:5179 가능성 → WGS84 변환 검토) → 최근접/반경

## C5. 편의 — 약국(NMC 15000576)·공중화장실(파일)·공공와이파이(OA-20883)
- 약국: WGS84 좌표 + 운영시간 / 화장실: WGS84(파일 선적재) / 와이파이: WGS84
- 반경 질의(화장실·와이파이 300m, 약국 500m) → 개수 + 최근접

## C6. 녹지 — 도시공원 표준 (15012890)
- 응답 핵심: 위경도 점좌표 → 최근접/~1km
- (둘레길 OA-11986 = 공공누리 4유형, **미사용**)

## C7. 안전 — 안심이CCTV(OA-20923)·보안등(표준)·침수흔적도(OA-15636)·5대범죄(OA-13532)
- CCTV/보안등: WGS84 좌표 → 반경 밀도 (방범CCTV OA-21097 = 4유형, **미사용**)
- 침수: 폴리곤(파일 선적재) → 점-in-폴리곤 이력
- 범죄: **자치구 단위**(행정동 불가) → 자치구 수준 표기

## C8. 지금 — 문화행사 (OA-15486)
- 응답 핵심: `LAT`/`LOT`(위경도), 시작/종료일, `GUNAME`
- 반경 500m + 기간 필터

## 공통 규약
- 호출: 서울 열린데이터광장 `http://openapi.seoul.go.kr:8088/{KEY}/json/{SERVICE}/{START}/{END}/...`
- 응답 1회 1,000건 제한 → 반경 사전 필터/페이지네이션
- 모든 좌표는 내부에서 WGS84로 통일(C-Transform)
- 실패는 카드별 격리(FR-010), 라이선스 공공누리 1유형만 사용
